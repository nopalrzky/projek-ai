# idea.md — Sidomulyo Motor + Sidomulyo Attendance Mobile

Dokumen ini menjadi peta ide, arah pengembangan, dan instruksi kerja untuk AI agent/Hermes saat mengerjakan dua repository:

* Backend/Admin: `sidomulyo-motor`
* Mobile Attendance: `Sidomulyo-attendance-mobile`

Fokus utama:

1. Menjaga backend Sidomulyo Motor sebagai pusat data operasional bengkel.
2. Menghubungkan aplikasi absensi mobile dengan backend utama.
3. Menjaga keamanan data runtime seperti `data/bengkel.db`.
4. Menstandarkan kontrak API mobile attendance.
5. Memberi roadmap teknis untuk stabilitas, audit, UX, deployment, dan fitur lanjutan.
